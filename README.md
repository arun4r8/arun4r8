# Hi, I'm Arun

I'm a student at UT Austin working across the stack, from silicon up to software: taking
digital designs from RTL to GDS, writing firmware for radios, and building AI agent
systems.

## Highlights

| Project | What it is |
|---|---|
| [**Processing-Element**](https://github.com/arun4r8/Processing-Element) | 16-bit fixed-point MAC processing element taken from RTL through a full Cadence flow on SkyWater 130 nm. Signoff-clean at **322 MHz**, 11,650 µm², 6.64 mW. |
| [**LumiAgents**](https://github.com/arun4r8/LumiAgents) | Agent orchestration platform on Cloudflare Workers + Supabase: six AI agents running company workflows as typed, auditable, resumable orchestrations. |
| [**fhss-firmware**](https://github.com/arun4r8/fhss-firmware) | Portable C99 frequency-hopping spread spectrum layer for the 902–928 MHz band, with a unit-tested FCC 15.247 hop schedule and an STM32 + SX1262 port. |
| [**Transformer-ML-Project**](https://github.com/arun4r8/Transformer-ML-Project) | Encoder–decoder Transformer built module by module in PyTorch. |
| [**4-bit-alu-verilog-project**](https://github.com/arun4r8/4-bit-alu-verilog-project) | 4-bit ALU in Verilog, structural and behavioural versions, simulated in Icarus/GTKWave. |
